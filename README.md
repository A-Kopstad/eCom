StoreOne is an online marketplace where users can buy and sell products. The platform provides an easy way for individuals to list products for sale, browse available items, and complete transactions in a secure environment.

## Features

StoreOne is a fully functional e-commerce platform designed for both buyers and sellers. It allows users to create accounts, list products, and manage purchases and sales with ease. Whether you're a casual seller or a shopper, StoreOne aims to provide a seamless and efficient experience.

- Product Listings: Users can add products for sale with descriptions, images, and pricing.
- Product Search & Filters: Browse through available products with search and filtering options based on categories, price range, and more.
- User Accounts: Create and manage personal accounts to track purchases, sales, and manage listings.
- Shopping Cart: Add products to a shopping cart and proceed to checkout for secure transactions.
- Transaction Management: Buyers can view order details, and sellers can manage their listings and orders.
- Responsive Design: A mobile-friendly design ensures the platform is accessible on various devices.
- User Reviews & Ratings: Buyers can leave reviews and rate products to help other users make informed decisions.

## Getting Started

### Prerequisites

Before getting started, make sure you have Node.js and npm installed on your system. You can check if they're installed by running the following commands:

```bash
node -v
npm -v
```
The first step is to clone the repository to your local machine. This will copy all the project files to your computer.
```bash
git clone https://github.com/A-Kopstad/projectExame2
```

After cloning, navigate into the project directory and install dependencies:

```bash
cd projectExame2
npm install
```

Then run code 
```bash
npm run build
```
